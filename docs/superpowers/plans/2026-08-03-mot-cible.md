# Mot cible (waypoint exact) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter un mot cible optionnel et persistant : un mot rare à atteindre qui, joué exactement et accepté par le portail, rapporte un gros bonus (× rang) puis une cible plus rare. Zéro guidage, aucune de ses lettres n'est jamais interdite, pas de refresh.

**Architecture:** Backend = un endpoint `GET /api/target` (sélection) + `Vocab.pick_target`. La **capture** est détectée côté client (`res.word === target` && hop accepté) → `/api/hop` inchangé. La protection anti-collision (ne jamais interdire une lettre de la cible) se fait en filtrant l'ordre des lettres côté client.

**Tech Stack:** FastAPI/numpy (backend), vanilla JS/CSS (front). **Pas de framework de test** → vérif **curl** (endpoint) + **navigateur** (preview « Vocabulium » sur `http://localhost:8077`, `javascript_tool`, `screenshot`). Bumper `?v=` à chaque tâche touchant le front.

```python
    def pick_target(self, current: str, avoid: str, captures: int) -> str | None:
        """Choisit une cible : rare (bande qui descend avec `captures`), SANS aucune
        lettre de `avoid` (interdites actives), != mot courant, et PAS immédiatement
        jouable depuis `current` (prox < TAU_GRACE) pour forcer un vrai chemin."""
        import random
        avoid_set = set(avoid)
        cur = self.canonical(current)
        cur_vec = self._M[self._words[cur]] if cur in self._words else None
        z_hi = max(C.ZIPF_MIN + 0.6, 4.8 - 0.5 * captures)
        z_lo = z_hi - 0.6
        cand = [w for w in self._id2word
                if z_lo <= self._zipf[w] <= z_hi
                and w != cur
                and not (avoid_set & set(fold(w)))]
        random.shuffle(cand)
        for w in cand:
            if cur_vec is None:
                return w
            if float(self._M[self._words[w]] @ cur_vec) < C.TAU_GRACE:
                return w
        return cand[0] if cand else None
```

@app.get("/api/target")
def get_target(current: str, avoid: str = "", captures: int = 0):
    w = db.pick_target(current, avoid, captures)
    if not w:
        return {"word": None}
    z = db.zipf(w)
    bonus = C.TARGET_BASE + round(C.TARGET_RARE_W * rarete(z))

- [ ] **Step 1 : `activeForbidden` filtre les lettres de la cible**

Dans `web/letters.js`, remplacer `activeForbidden` par :
```js
  // Lettres interdites actives = les `forbiddenCount` premières de l'ordre, en
  // SAUTANT celles de la cible (jamais interdites). On maintient le compteur en
  // puisant plus loin dans l'ordre.
  function activeForbidden(order, words, every, start = 0, targetLetters = []) {
    const skip = new Set(targetLetters);
    const avail = skip.size ? order.filter((L) => !skip.has(L)) : order;
    return avail.slice(0, forbiddenCount(words, every, start));
  }
```
(La signature garde `targetLetters` optionnel → rétrocompatible.)

Ajouter (près de `activeForbidden`) :
```js
function targetLetters() {
  return S.target ? [...new Set([...S.target].map(Letters.fold))] : [];
}
function renderTarget() {
  if (!S.target) { el.cible.style.display = "none"; return; }
  el.cible.style.display = "";
  el.cibleWord.textContent = S.target;
  el.cibleBonus.textContent = "+" + S.targetBonus;
}
async function fetchTarget() {
  const avoid = activeForbidden().join("");
  for (let tries = 0; tries < 4; tries++) {
    let r;
    try {
      r = await fetch(`/api/target?current=${encodeURIComponent(S.current)}`
        + `&avoid=${avoid}&captures=${S.captures}`).then((x) => x.json());
    } catch (e) { return; }
    if (!r.word) { S.target = null; break; }
    if (!S.played.has(r.word)) { S.target = r.word; S.targetBonus = r.bonus_base; break; }
  }
  renderTarget();
  renderForbidden();   // la protection dépend de la cible -> re-render
}
```
